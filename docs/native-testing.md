# Jhih‘s FilmLab v0.7.5 Sepia 候选版机内测试说明（仅离线验证）

[English](native-testing.en.md) · [简体中文](native-testing.md)

作者：@Jhih he

本候选版将 22/82 Sepia 的 Toning 设为 7；这是离线固件分析结果，尚未实机验证。所有 82 组色彩验收仍待完成。

仅 Sigma fp 固件 5.02。关机后将本包 AutoRun.txt、FilmLab.BIN 替换到卡根目录，每次开机仅加载一次。不修改或刷新固件。
旧 v0.3.4 已由用户确认切换、取景变化和拍摄变化。v0.7.1 修正固件参数槽与整数步长，v0.7.2 新增Effect/Toning中性基线及原值恢复；中文HUD和本版参数写入均尚未通过实机验收。

## v0.7.4 白平衡模式与显式槽修复

请停用v0.7.3：该版仅绕过偏移读值归零，未绕过黑白模式下白平衡模式本身归零，可能持续重试或访问错误WB槽。v0.7.4直接读取原始WB模式与色温，并用原固件枚举映射显式槽位读写BA/GM，不依赖被黑白归零的“当前模式”解析。实际原固件getter、存储解析、公开设置器及word store已在12种WB模式的准备环境中执行；singleton backing配置、颜色标量、通知/commit为边界，仍不构成实机验收。

## 读回、重试与白平衡原值

本版增加完整参数读回后再标记应用完成；busy跳写时保持待完成，约500ms重试，新请求可绕过旧请求等待。应用和恢复末尾复查WB/色彩模式，避免读回期间模式变化误报成功；这些复查不构成跨线程原子保证。

BA/GM快照和核验使用固件属性的原始word存储接口，避免黑白模式下公开getter将偏移归零，保留原始隐藏偏移用于恢复。12种原始白平衡模式的82组应用/恢复已离线验证；并非12种模式全部实机通过。

此包是SD卡运行时加载程序，不是官方固件更新文件；82组尚无完整实机色彩验收，官方COLOR菜单仍未接入。首次验证请在可随时移走加载文件的卡上操作。若异常，关机移走AutoRun.txt和FilmLab.BIN，完全断电后重新开机。

## v0.7.2 基线设置

切换方案时Effect、Toning明确设为0，避免继承此前原厂强度或黑白色调。“恢复原始设置”也恢复这两项，包括Effect当前未显示的底层值。首次实机测试应记录原厂Effect/Toning，应用方案后检查中性基线，恢复后检查15个原厂风格设置；测试不同Toning开关下的Effect是否保持原值。操作需在相机可连接时完成，当前没有完成这些实机验证。详见《原厂风格基线说明.md》。

## v0.7.1 固件调用修正

目录中的三项调整保留 -5…+5 界面档位，实际设置器写入乘2后的 -10…+10 偶数；读取的启动快照直接原值恢复。PowderBlue 模式编号13转换为参数槽12。详见《固件ABI修正说明.md》。旧版对比/锐度/饱和可能写入不被ISP转换器接受的奇数，因此本版照片与旧版可能明显不同，不能用旧版变化证明本版正确。82条色彩方案仍为0条完成全项实机验收，官方COLOR菜单尚未集成。

## 操作

在正常拍摄预览界面按住 AEL：左/右一次切换一个，82条首尾循环，上/下一次切换十个，OK 恢复加载时参数。保持方向不会连续切换；释放方向再按会切换。不要在原厂菜单或回放界面切换，插件尚未阻断这些界面中的原厂按键行为。

## 避免意外截图

适马原厂截图组合键为 DISP＋OK，或按住 DISP 加回放/TONE/COLOR/MODE。也能自定义到单键。
请在 SHOOT（拍摄）→ Custom Buttons Functions（自定义按钮功能）→ AEL，检查是否分配为 Screenshot（截图）；如是，改为 AEL (Pressed)（按下期间曝光锁定）或适合自己的其他功能。回放界面的 AEL 默认还可切换显示过滤。请在 PLAY（回放）→ Filtering Options for Display（显示过滤选项）中选择 Display All（显示全部）或 Still Images Only（仅静态图像），检查是否误用了 Screenshot Only（仅截图）。
监听不会吞掉原厂事件，因此 AEL 仍执行用户分配的功能。程序不自动修改自定义按键或删除照片。
截图是1024×682 JPEG，文件名SS__xxxx.JPG，回放可显示截图图标。正常拍摄文件与截图同目录，正常快门照片并未被截图替换。请用快门拍摄并检查文件名。
官方依据：https://www.sigma-global.com/en/support/download/fp_Manual_FW_Ver.5.0_EN_2.pdf 第88、141、161页。

## 验收

1. 冷启动等待完成，确认中文名称、原厂图标可读，红字位于ISO状态栏下方。
2. 切到02、03，再松开AEL和方向，观察中文名字持续显示，无乱码或KEY/H1残留；切到较短名称确认无旧字残影。
3. 拍摄并回放确认名称能恢复显示、预览/照片仍变化；检查无新SS__截图（须先检查原厂自定义键）。
4. 如果变黑、图标消失、闪烁或卡死，停用本版，并反馈出现在哪一步。断开所有供电、移走AutoRun.txt与FilmLab.BIN即可恢复原厂加载路径。

保留77条来源配方，新增5条哈苏参考方案，总计82条、73组独立目标参数。新增方案来源见哈苏参考方案来源.md；完整适配差异、重复组和校准拍摄要求见适配核对报告.md。没有Sony目标样本与定量校准，不能称为完美复刻。

## v0.5.0 数值调整

Sony常规±3调整按5/3转换为fp±5索引，四舍五入并封顶；它是范围归一化近似，未经光学校准。Sigma原生新增哈苏方案保留原强度。自动WB写入Auto(Natural)=41并恢复同一槽，固定K不变。Light改PowderBlue，Night改Neutral，Autumn改SunsetRed；黑白清零饱和度；rough-mono用黑白/+5对比度；pop-color用+5饱和度。保留所有Sony原始字段。AB/GM沿用原映射，未从屏幕样本拟合增益。

## v0.5.1 名称

完整中英文品牌/方案名见中英文完整名称.md。机内仍用英文短名，82种可区分，不默默截断；本版尚未加入中文点阵字库。数值沿用v0.5.0，仅名称与顺序变化。

## v0.7.0 动态HUD验收

检查明亮与暗背景下白字、黑描边是否清楚，切换时两行是否完整；停止操作约3秒后第二行应消失。检查回放/拍摄后是否有残影、闪烁或原厂图标受影响。异常时关机断开全部供电，移走AutoRun.txt和FilmLab.BIN恢复原厂启动路径。
安装使用AutoRun.txt＋FilmLab.BIN，删除旧fpSup.BIN；不要混用旧AutoRun配置。滤镜数值与v0.6.1一致。Noto字库许可证随包附带。中文、描边透明性与两行刷新尚需真实相机验证，本地模拟不代表机内稳定性。
